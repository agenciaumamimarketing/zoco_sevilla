# Datos

- `zoco-palabras-para-planificador.csv`: las 67 búsquedas del anexo del plan, una sola columna `Keyword`, lista para subir al Planificador de Google Ads.
- `zoco-palabras-por-grupo.csv`: las mismas, con su grupo (grupos, brasa, carta/turistas, vinos, cócteles, música, marca) y columnas vacías para volcar volumen, competencia, pujas y la decisión (incluir / probar / descartar).
