# 03 · Fidelizar: más razones para volver

Prioridad: que la visita merezca repetirse antes de pedir una nueva reserva.

1. **[Cuidar la experiencia](canales/experiencia.md):** cocina, servicio, ambiente y un recuerdo para llevarse.
2. **[ZOCO HABIBIS](canales/zoco-habibis.md):** una comunidad, no un grupo comercial.
3. **[Conseguir reseñas](canales/resenas.md):** objetivo interno 4,78 para un 4,8 sólido. Habibifest al lograrlo.

Para grupos: comunicación directa caso por caso; después de la cena, agradecer, preguntar cómo fue y proponer otra ocasión (comida de equipo, cumpleaños, evento).
